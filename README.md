# ДОРСЕТЬ — фронтенд (лабораторная 5)

SPA на **React + TypeScript + Vite** с компонентами **React-Bootstrap** для гостя. Тема — строительство дорожной сети: услуги — города с координатами.
Интерфейс сделан под вертикальный экран телефона: в браузере на компьютере приложение показывается «телефоном» шириной 390px по центру. Дизайн (цвета, шапка, нижняя панель, лента, карточки, фильтр) перенесён из ЛР1 — `static/css/style.css` бэкенда — и наложен на компоненты React-Bootstrap через `className`.

Бэкенд: [road-network-backend](https://github.com/leewnaaa/road-network-backend) (FastAPI).

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production-сборка в dist/
```

Бэкенд не нужен: в лабораторной 5 все данные берутся из коллекции mock-объектов `src/modules/mock.ts`, запросов к API нет, поэтому во вкладке **Network** нет ошибок — видны только загрузки страницы, `DefaultImage.jpg` и `DefaultVideo.mp4`. Источник данных показывает плашка **«данные: mock»** на каждой странице.

Для подключения к бэкенду (ЛР6) запустите фронтенд с переменной `VITE_USE_MOCK=false` (например, в файле `.env.local`). Тогда запросы `/api/...` пойдут через proxy Vite на `http://127.0.0.1:8000` (см. `vite.config.ts`), а при ошибке данные снова возьмутся из mock.

## Страницы

Внизу экрана находится навигационная панель из 4 пунктов: **Лента**, **Добавление**, **Плитка**, **Вход**. Гостю доступны только «Лента» и «Плитка». «Добавление» и «Вход» неактивны (серые, не нажимаются). Активный пункт подсвечивается оранжевой чертой.

В шапке находится логотип **ДОРСЕТЬ** (ведёт на ленту).

### 1. Лента — `/` и `/?city_id=<id>`

Полноэкранное видео города в стиле reels.

| Элемент | Что делает |
|---|---|
| Видео на фоне | видео города; если поле `video_url` пустое или файл не загрузился, показывается видео по умолчанию `public/DefaultVideo.mp4` |
| Плашка «данные: mock / API» | источник данных |
| 🤍 и число | количество лайков (гость лайкать не может) |
| Кнопка **i Подробнее** | переход на страницу города |
| Кнопка **→ Дальше** | следующий город по порядку публикации; после последнего — снова первый |
| Название, 📍 координаты | данные города |
| Описание и кнопка **Ещё... / Свернуть** | раскрывает и сворачивает длинное описание |

Без параметра показывается самый новый город, с `?city_id=` — указанный.

### 2. Плитка — `/cities`

Список опубликованных городов в 2 колонки с фильтром.

| Элемент | Что делает |
|---|---|
| Список сортировки | «По названию (А–Я)», «Сначала новые», «По числу лайков» |
| Поле **«Поиск по названию»** | оставляет города, в названии которых есть введённый текст |
| Ползунок **«Широта до: N°»** (40–70) | фильтр по широте, как параметр `lat_max` бэкенда; список обновляется через 300 мс после остановки ползунка |
| «найдено: N» | количество карточек после фильтрации |
| Кнопка **Сбросить фильтр** | возвращает фильтр к значениям по умолчанию |
| Карточка: фото, название, 📍 координаты, ❤️ лайки | фото по умолчанию `public/DefaultImage.jpg`, если `image_url` пустой или не загрузился |
| Плашка **Подробнее** (клик по всей карточке) | страница города |

Значения фильтра хранятся в адресной строке (`/cities?q=ка&lat_max=56&sort=likes`), поэтому сохраняются при возврате со страницы «Подробнее» и при обновлении страницы.

### 3. Подробнее — `/cities/:id`

| Элемент | Что делает |
|---|---|
| Хлебные крошки **Плитка / Город** | возврат к плитке |
| Фото | фото города или изображение по умолчанию |
| Название, плашка источника, описание | данные города |
| Таблица: координаты, дата публикации, лайки | данные города |
| Кнопка **Смотреть в ленте** | лента, открытая на этом городе |
| Кнопка **Назад** | предыдущая страница |

## Структура

```
public/
  DefaultImage.jpg, DefaultVideo.mp4   изображение и видео по умолчанию
src/
  main.tsx              точка входа, подключение bootstrap.css
  App.tsx               роутинг (react-router-dom)
  AppLayout.tsx         оболочка: шапка + <Outlet/> + нижняя навигация
  Routes.ts             адреса страниц и подписи пунктов меню
  components/
    AppHeader.tsx       шапка
    BottomNav.tsx       нижняя навигация из 4 пунктов (Nav из React-Bootstrap)
    CityCard.tsx        карточка города (Card)
    CityFilter.tsx      фильтр плитки (Form.Control, Form.Range, Form.Select)
    CityImage.tsx       <img> с подменой на изображение по умолчанию
    CityVideo.tsx       <video> с подменой на видео по умолчанию
    SourceBadge.tsx     плашка «данные: mock / API» (Badge)
  index.css             дизайн из ЛР1 поверх React-Bootstrap
  hooks/
    useCities.ts        загрузка списка городов с фильтром по широте
    useDebounce.ts      задержка значения ползунка
  modules/
    types.ts            типы City, CityFeed, CityFilters
    mock.ts             коллекция mock-объектов (8 городов)
    citiesApi.ts        получение данных: mock (ЛР5) или API при VITE_USE_MOCK=false
    media.ts            файлы по умолчанию, форматирование координат и дат
  pages/
    FeedPage.tsx        лента
    CitiesPage.tsx      плитка
    CityPage.tsx        подробнее
```

## Используемые хуки

| Хук | Где | Зачем |
|---|---|---|
| `useState` | все страницы, `CityImage`, `CityVideo`, `useCities`, `useDebounce` | данные города и списка, загрузка, источник, раскрытие описания, текущий файл медиа |
| `useEffect` | `FeedPage`, `CityPage`, `useCities`, `useDebounce`, `CityImage`, `CityVideo` | загрузка данных при монтировании и смене id или фильтра; в cleanup — отмена запроса (`AbortController`) и таймера |
| `useMemo` | `CitiesPage` | фильтрация по названию и сортировка пересчитываются только при изменении данных или фильтра |
| `useNavigate` | страницы | переходы по кнопкам |
| `useParams` | `CityPage` | `id` города из адреса `/cities/:id` |
| `useSearchParams` | `FeedPage`, `CitiesPage` | `city_id` ленты и значения фильтра в адресной строке |
| `useLocation` | `BottomNav` | подсветка активного пункта меню |
| `useCities` (свой) | `CitiesPage` | загрузка списка с `lat_max` |
| `useDebounce` (свой) | `CitiesPage` | не отправлять запрос на каждый шаг ползунка |

Context и Redux не используются: состояние живёт в страницах и передаётся дочерним компонентам через props.

## Методы API (используются при `VITE_USE_MOCK=false`)

| Метод | URL | Страница |
|---|---|---|
| GET | `/api/cities?lat_max=` | Плитка |
| GET | `/api/cities/feed` | Лента без параметра |
| GET | `/api/cities/feed/{id}` | Лента с `city_id`, Подробнее |
| GET | `/api/cities/feed/{id}?next=true` | кнопка «Дальше» |
